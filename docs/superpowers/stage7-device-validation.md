# Stage 7 实机验收清单

本文档对应 Compose UI 重构计划的阶段 7。仓库内已完成自动化测试、编译、静态检查和 APK 生成；以下项目需要在真实 Android 环境执行，当前工作区不具备 `adb`/模拟器，因此不伪造执行结果。

## 测试矩阵

| 维度 | 必测值 |
| --- | --- |
| Android | API 30 arm64、API 35 arm64 |
| 性能档位 | 普通设备/模拟器、低性能设备/模拟器 |
| 屏幕 | 360dp 竖屏、360dp 横屏、600dp、840dp 或平板 |
| 外观 | 液态玻璃、轻量液态、旧版经典 |
| 语言 | 中文、English、Русский |

每个组合至少检查：启动器、设置、Workshop 列表、Workshop 详情、下载中心、模组库和控制编辑器。液态玻璃模式应显示背景/玻璃层；轻量液态模式应可用但不出现明显卡顿；旧版经典模式不应依赖玻璃效果。

## 功能回归路径

1. 冷启动应用，确认默认进入启动器；切换一级模块，再返回启动器。
2. 在设置中依次选择三种外观，退出并重新进入应用，确认选择持久化。
3. 切换中文、英语、俄语，检查标题、按钮、错误/空状态和控制编辑器面板没有硬编码中文或截断。
4. 在启动器打开已有实例、创建/编辑实例入口、删除确认、备份/恢复和游戏启动入口。
5. 在 Workshop 搜索、排序、分页，打开模组详情；检查轮播、详情内图片、评论、依赖和下载入口。
6. 在下载中心检查任务进度、暂停、恢复、重试、取消、删除、日志和进程重启后的恢复。
7. 在模组库检查版本列表、更新检查、清理、删除、分享、安装到多个实例及覆盖/保留备份确认。
8. 打开控制编辑器，检查画布命中/拖动、长按添加、布局替换、自定义图标、删除和保存；再打开硬件手柄映射入口。
9. 启动游戏，确认 `GameActivity` 游戏画面、游戏内触控覆盖层和返回行为与重构前一致。

## 性能与降级观察

- 冷启动和一级模块切换不应出现黑屏、无限加载或明显主线程阻塞。
- Workshop/模组库列表连续滚动 30 秒，观察掉帧、图片加载和内存增长；返回再进入后不应叠加重复内容。
- 详情页打开、轮播切换和返回应保持响应；无网络时应进入错误/空状态并可重试。
- 液态玻璃在 API 30 和低性能环境出现渲染异常时，应能回到可读的轻量表面；用户选中的外观仍需保持。
- 旋转屏幕、切换横竖屏和杀进程重启后，外观、语言、当前实例/任务等已持久化状态不应被错误重置。
- Android 13+ 通知权限、前台下载通知和后台下载恢复均需实际确认。
